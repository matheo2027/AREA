## Configuration d'Express.js

### Installation
- Assurez-vous que Node.js est installé.
- Installez les dépendances avec `npm install`.

### Démarrage
- Lancez le serveur avec `node index.js`.
- Le serveur est accessible à `http://localhost:3000`.

### Structure
- `routes/` : Contient les définitions de routes.
- `middlewares/` : Contient les middlewares globaux.
